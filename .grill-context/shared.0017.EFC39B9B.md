+ Note
  What a Dictionary Entry is, in the user's words: "my sister", "container orchestration tool". It is sent with its Spelling Hint only to modes that rewrite what was said, so they can tell which entry a misheard word meant. It is never sent to a mode that writes new text, where the model treats it as material, nor to a Transcription Model.

  under: Substitutions

~ Substitution Convergence
  Two Dictionary Entries holding an identical Replacement are one entry that two devices created separately, and a sync pass merges them into it: the entry made first survives, the Trigger Phrases combine, and the other is deleted. The survivor keeps its own Note, or takes the Note of the most recently edited other entry when it has none. An entry with no Trigger Phrases converges the same way, so a Spelling Hint made on one device and a Substitution for the same Replacement made on another become one entry. It is not a Trigger Phrase Clash.
