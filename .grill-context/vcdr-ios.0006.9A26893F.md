+ Prompt Mode
  One of the two fixed ways iOS processes a transcript — Dictation or Assistant — each naming the AI Provider that runs it and whether Apple's on-device model stands in. It is a closed pair the app ships, not a list a person authors, which is what separates it from the macOS Mode; a Style is a separate choice that a Prompt Mode does not carry.
