+ Capture Use
  What a Mode does with the Captures collected during a Capture Session: not used, sent as input, or appended to output. Captures are collected in every Mode, because the Mode can change while recording; the Mode that processes the run applies its Capture Use. The Verbatim and Dictation Mode Templates fix Capture Use to not used: a Mode from those templates always has that Capture Use, whatever choice it has saved. Other Modes use the choice the user made.

  under: Context Capture
