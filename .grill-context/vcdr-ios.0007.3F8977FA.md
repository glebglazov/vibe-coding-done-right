~ Prompt Mode
  One of the three fixed ways iOS handles a recording — Verbatim, Dictation or Assistant — each naming the Transcription Model it records with and, where it processes the transcript, the AI Provider that does it. It is a closed set the app ships, not a list a person authors, which is what separates it from the macOS Mode; Verbatim names no AI Provider because it processes nothing, and a Style is a separate choice no Prompt Mode carries.
