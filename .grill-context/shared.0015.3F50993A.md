+ Pin
  What one Mode's Transcription Override does to a Transcription Model: points at it deliberately, in departure from the Default Transcription Model, and stays there. Only an override pins — a Mode that carries none pins nothing and uses whatever the Default is at the time. Unpinning is clearing the model from the override, which returns that Mode to the Default rather than to any particular model.
  avoid: name, bind, claim, require, assign, use
  under: Transcription

~ Transcription Override
  A departure from the Default Transcription Model carried by one Mode on macOS or one Prompt Mode on iOS. It pins a model, and may additionally carry settings keyed by that model's Transcription Model Family — so it may override the model alone and inherit the family's settings, or override individual settings too, with anything unset falling through to the family's own.

~ Transcription Model Library
  Every Transcription Model this platform offers, each with the state it is in on this device — not installed, downloading, installed, ready, or beyond this device's reach. It is never shortened: a model whose installability is not known yet is a row that says so. It is also the one surface a person installs a model from and removes one from. Only the Default Transcription Model cannot be removed; a model Modes pin is removable once the person has been told which Modes pin it and has agreed, which unpins them.
