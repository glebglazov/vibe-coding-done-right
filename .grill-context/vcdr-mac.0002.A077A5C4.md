+ Activation Hotkey
  The key combination on an Output Destination that, pressed while a Capture Session is recording, creates a Destination Override for that Capture Session. An Activation Hotkey is armed from the live Output Destination list, so binding, re-binding or clearing one takes effect for the next key press rather than at the next launch.
  avoid: destination shortcut, quick key, output hotkey
  under: Output Delivery
