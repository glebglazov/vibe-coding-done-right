+ Transcription Override
  A departure from the Default Transcription Model carried by one Mode on macOS or one Prompt Mode on iOS. It names a model, and may additionally carry settings keyed by that model's Transcription Model Family — so it may override the model alone and inherit the family's settings, or override individual settings too, with anything unset falling through to the family's own.
  avoid: mode model, per-mode model, transcription preference
