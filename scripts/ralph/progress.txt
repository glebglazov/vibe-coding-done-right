## Codebase Patterns
- All dependencies are wired through AppDependencies.swift (DI container)
- Use OSLog via Logger extensions, never print()
- Named constants for all numeric literals
- Protocol-first design for new subsystems
- CapturePanel is the NSPanel controller; CaptureViewModel holds the state; CaptureView is the SwiftUI view
- RecordingCoordinator.State has 5 cases: idle, preparingToRecord, recording, transcribing, error — no .executing
- PostTranscriptionActionType enum and TranscriptionRecord.swift are legacy migration decoders — still needed, don't remove
- onWillStartRecording (RecordingCoordinator) and onWillStartInput (CaptureCoordinator) are distinct entry points for voice-recording and push-to-type flows respectively — both are live
- Xcode project uses fileSystemSynchronizedGroups — new files are auto-discovered, no manual project file edits needed
- Use ClipboardHelper.writeString() for clipboard writes, KeyboardSimulator for CGEvent keystroke simulation, CopiedFeedback.trigger() for copied state feedback
- Use panelOriginBelowMenuBar() for panel positioning, panel.configureAsOverlay() for NSPanel setup, removeEventMonitor() for event monitor cleanup (PanelHelpers.swift)
