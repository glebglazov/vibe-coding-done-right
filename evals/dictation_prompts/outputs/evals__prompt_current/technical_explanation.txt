So the way the caching layer works is basically: you have your primary cache, which is Redis, and then behind that you have a secondary in-memory cache on each node. And when a request comes in, it first checks the local cache. If it's not there, it goes to Redis. If it's not in Redis either, then it hits the database. The tricky part is invalidation because you have to invalidate both layers. And if you only invalidate Redis but not the local cache, you get stale data for up to 30 seconds, which is the TTL on the local cache. We had a bug with this last month, actually, where prices were showing wrong for some users because of exactly this issue.
