The way the caching layer works: you have your primary cache, which is Redis, and behind that you have a secondary in-memory cache on each node. When a request comes in, it first checks the local cache, and if it's not there it goes to Redis, and if it's not in Redis either then it hits the database.

The tricky part is invalidation because you have to invalidate both layers. If you only invalidate Redis but not the local cache, you get stale data for up to 30 seconds—which is the TTL on the local cache. We had a bug with this last month where prices were showing wrong for some users because of exactly this issue.
