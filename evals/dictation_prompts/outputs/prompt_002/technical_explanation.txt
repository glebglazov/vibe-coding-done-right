So the way the caching layer works is: you have your primary cache, which is Redis, and then behind that, you have a secondary cache, which is in-memory on each node. When a request comes in, it first checks the local cache. If it's not there, it goes to Redis. If it's not in Redis either, it hits the database. The tricky part is invalidation because you have to invalidate both layers. And if you only invalidate Redis but not the local cache, you get stale data for up to 30 seconds—the TTL on the local cache. We had a bug with this last month where prices were showing wrong for some users because of exactly this issue.
